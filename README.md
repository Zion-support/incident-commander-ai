# Incident Commander AI

AI incident commander that detects, triages, coordinates, and resolves production incidents — from first alert to postmortem.

## Features
- Automatic incident detection & severity classification
- Runbook-driven remediation suggestions
- War-room coordination (paging, comms, timelines)
- AI-generated postmortems with action items
